# Focus Island · 桌面灵动岛倒计时

透明无边框专注计时器，使用 Rust + tao + wry。Windows 使用 WebView2，已有本机验证的便携包；macOS 使用 WKWebView，Apple Silicon 与 Intel 包已完成一次云端构建和 GUI 自检，尚需人工实机验收。界面、脚本、托盘图标均内置。

## 运行

双击 **dist/FocusIsland.exe**。系统需已有 Microsoft Edge WebView2 Runtime；发布包不包含该系统运行时。

- 收起态为屏幕水平居中、顶部距离可设为 0–1000 px（默认 20 px）的 132×38 药丸，实际开始计时后（含暂停）优先显示倒计时和进度环。未开始任务时显示待机，即使列表里保留了选中任务；待机可显示时分秒或恶魔之眼；两项都开启时每 10 秒轮换，只开启一项时持续显示该项。
- 点击展开为 340×340 圆盘：真实时钟、金色倒计时环、数字电子窗、播放/暂停和重置。点击不显示岛体描边，表盘展示正在执行的任务名称，不展示任务提示卡片；任务列表仍保留选中标识。
- 右键打开右下角的独立功能面板，按住顶部标题区可拖动，关闭再打开保留本次位置和页面。左侧菜单分为「倒计时」「Webhook」「手机通知」「通用设置」四项：倒计时管理时长与任务，Webhook 管理服务器连接与本机接收，手机通知管理蓝牙连接与隐私，通用设置管理通知框、位置、待机和提醒。任务列表旁的「新增任务」进入独立页面，可一次填写名称、时长和结束动作；返回保留完整草稿，创建成功后返回并选中新任务。
- 倒计时归零时左右半盘沿互补锯齿分离，伴随白光、光束、金色火花与冲击波；约 1.5 秒后显示绿色完成态。从归零起 10 秒后自动收起并恢复所配置的待机内容，点击已完成的灵动岛（包括动画中）可立即恢复；任务仍保留，结束动作按原计划执行。
- 药丸通过原生窗口区域接收点击，透明角落和画布留白可直接穿透。展开态保持可交互。
- 托盘菜单提供功能面板、显示/隐藏、退出。关闭功能面板只隐藏它。
- 任务列表选中项决定下次开始的目标；未开始、选择任务和重置后均显示待机。开始后优先显示倒计时，暂停保留剩余时间；完成结果显示至自动或手动恢复待机。运行、暂停和完成后的等待阶段显示任务名，待机时隐藏；重置保留任务和设定时长。「待机时间」只控制待机数字时钟，不影响任务倒计时和独立的指针开关。
- 空格开始/暂停；Esc 收起圆盘。功能面板中 Esc 优先收起执行类型菜单，新增任务页或任务设置页按 Esc 返回倒计时页，四个根页面按 Esc 关闭浮窗。菜单支持 Tab 和方向键移动焦点、Enter 或空格切换；切换菜单保留各页草稿与滚动位置，不暂停或重置计时。

任务、当前设定时长和偏好保存在 **%APPDATA%\FocusIsland\state.json**。时长精确到整秒，上限 99:59:59。运行中修改显示偏好不会重置倒计时；应用新时长或切换任务会停止并重置。重启恢复配置，计时器处于待开始状态。


## 通知框

功能面板 → 通用设置 → 通知框可开关消息展示，设置停留时间（1–30 秒，默认 5 秒）和列表数量（1–10 条，默认 5 条），并通过「发送测试通知」直接预览。

收到消息后，当前岛右侧以水滴分离动画出现玻璃消息岛，两岛整体水平居中。主岛收起时消息岛最大宽 280px，主岛展开时为 196px；超长标题和正文使用省略号。主岛继续显示原来的时间、待机或倒计时。

停留时间到后，消息岛收缩为未关闭的消息数量。点击数量向下展开列表，按接收顺序显示前 N 条；勾选消息旁的选框即关闭该条，后续未展示消息自动补位。预览超时不会删除消息；同 ID 更新替换原消息且不延长展示，来源撤回会同步移除。最多保留 200 条内存消息，关闭通知框或退出程序会清空。

主岛和消息岛共用固定 580×580 透明画布；稳定显示时仅岛体、柔影和列表区域接收点击，间隙可穿透。归零特效期间暂停通知展示，特效结束后恢复数量，不重复播放旧预览。减少动态效果时直接切换。

通知展示与手机连接独立；支持手机消息、Webhook 与本机测试通知。


## Webhook

功能面板 → Webhook 的“服务器连接”用于公网接入：填写 HTTPS 服务地址和服务器生成的 64 位连接密钥，开启并保存。程序自动连接、收取消息，断线后自动重试；成功连接后可复制专属 Webhook URL。电脑无需配置 SSH 或开放入站端口。重新打开程序会恢复已保存的连接，密钥输入框留空表示保留已有密钥；更换服务器地址时必须重新填写密钥。

公网服务 **https://webhook.tchenmm.online** 已上线，可将该地址填入“服务器连接”，再填写服务器提供的连接密钥；专属投递地址从连接成功后的面板复制。自行部署其他服务器时，使用 [deploy/relay/README.md](deploy/relay/README.md)；仅填写域名不会自动安装服务器。服务器管理密钥与外部 URL 内的投递令牌相互独立，不向外部调用者提供管理密钥。连接密钥只保存在本机应用配置中，页面不会回显保存的密钥。

中继每次最多发送 20 条消息；灵动岛确认已接收后才 ACK，暂时断网或关闭通知框时保留在服务器队列中等待重连。服务器运行期间最多暂存 200 条、保留 24 小时，满队列返回 429。队列与桌面消息均只存内存，重启服务会清空待收消息；已确认的桌面消息不在应用重启后恢复。第一版一个服务连接密钥对应一台电脑；多台电脑使用同一密钥会竞争消费，不提供广播。

也保留独立的本机/局域网接入：开启本机接收，选择范围与端口（默认 17891），保存后复制对应的本机 URL。首次保存自动生成随机令牌，“更换令牌”使旧本机地址失效；它与服务器投递令牌分别管理。“发送测试消息”验证本机接收，通知框关闭时本机请求返回 503。

外部程序向专属地址发送 POST，设置 `Content-Type: application/json`。支持飞书文本消息结构：

~~~json
{"msg_type":"text","content":{"text":"部署完成"}}
~~~

也支持自定义通知：

~~~json
{"id":"build-123","app":"CI","title":"构建成功","body":"版本已准备完成"}
~~~

`id` 可省略；同来源同 ID 更新原消息，发送 `{"type":"removed","id":"build-123"}` 撤回。消息进入现有通知框，使用同一停留时间、数量岛和列表，不影响倒计时、待机或任务结束动作。标题和正文按纯文本显示，只存内存。

PowerShell 示例（将占位地址替换为应用中复制的地址）：

~~~powershell
$body = @{ msg_type = 'text'; content = @{ text = '部署完成' } } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri 'YOUR_WEBHOOK_URL' -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
~~~

成功返回 HTTP 202，正文含 `ok: true`、`code: 0`。高级客户端也可使用 `POST /api/webhook` 配合 `Authorization: Bearer <令牌>`。本接口兼容飞书文本消息结构，不包含飞书卡片、签名或平台机器人管理功能。

本机模式只监听 127.0.0.1，局域网模式监听 IPv4 网卡；其他设备使用本机局域网地址，系统防火墙需允许对应端口。请求体上限 16 KiB，每分钟最多接受 60 个通过鉴权的请求；本机/局域网直接接口要求 Content-Length，不接受 chunked 编码、浏览器 Origin 请求或跨域调用。访问令牌保存在应用配置中，不写入日志，不发送到主岛页面；消息内容不落盘。

高级用户也可使用旧的 HTTPS 反向代理与 SSH 隧道方案，说明见 [deploy/webhook/README.md](deploy/webhook/README.md)；这是本机接收端的可选转发方式。新用户优先使用上面的服务器连接，不必运行隧道脚本。配置保存失败时保留原服务与草稿，退出应用关闭监听和后台连接。

## 手机通知（Windows + Android 第一版）

功能面板 → 手机通知中启用蓝牙同步。Android 伴侣工程和手机端说明位于 [android/README.md](android/README.md)。手机先开启通知访问，与 Windows 完成系统蓝牙配对，在伴侣 App 中选择允许共享的电脑并启动共享，然后在电脑端扫描并连接手机。首次安装默认关闭，首次扫描和配对由用户主动发起；连接成功后记住设备，启用状态下重新启动尝试重连。

手机消息统一进入「通知框」，主岛保持时钟、待机眼睛或倒计时，右侧独立展示消息；停留时间和列表数量在「通用设置 → 通知框」统一配置。手机端可选择同步的应用，电脑端可选择仅显示应用名。断连、停用共享或撤销通知授权清除手机来源消息，不影响其他来源与倒计时。正文只作纯文本并保存在内存中，不写入配置或诊断日志，不触发任务结束指令。

当前手机接收模块使用 BLE GATT，要求电脑与手机支持低功耗蓝牙。macOS 桌面功能保留，手机通知页显示暂不支持；iPhone ANCS 尚未接入。通知获取范围由 Android 通知访问权限和系统政策决定。编译及模拟通知测试不等同于真机蓝牙验收，锁屏、后台、省电策略和断线恢复需使用目标手机验证。
## 倒计时结束动作

新增任务页可直接配置「结束后执行」，与任务一起保存。新建草稿独立于当前任务，默认关闭；创建成功后下一份草稿恢复默认关闭。已有任务通过任务行的设置按钮进入专属页面，按分钟和秒编辑时长或修改结束动作。两项独立保存；修改当前任务时长会暂停并重置倒计时，修改其他任务不影响当前计时，相同时长保存不重置。校验或保存失败时保留草稿。设置主页没有独立的动作配置。结束动作只属于任务，无任务的自由计时不执行动作。动作默认关闭，可选择 PowerShell 自定义命令、锁屏、睡眠、关机或重启，各任务独立保存。自定义时长仍属于当前任务。

执行类型使用玻璃风格下拉菜单，带选中标记，可用方向键选择、Enter 确认、Esc 收起。启用后选择动作、填写命令与延迟并保存。执行延迟默认 10 秒，可设 0–300 秒。仅对应任务的设置页显示本次动作，尚未执行时可取消。保存修改会撤销该任务本次待执行动作，新设置下次开始计时生效。

自定义命令使用 Windows PowerShell，例如 `Start-Process notepad.exe`；工作目录为程序所在文件夹，任务名不会拼入脚本。后台执行不阻塞界面，反馈执行状态或失败结果。取消不会强行终止已经启动的外部程序；关机、重启不强制关闭应用。

暂停续用本次动作；重置、切换任务、修改当前任务时长、新计时和退出取消待执行动作。完成后自动或点击恢复待机只改变显示，不取消待执行动作。每轮最多执行一次，重启只恢复配置，不补执行上次动作。

## 构建

标准环境需要 Rust MSVC 工具链、Visual Studio C++ Build Tools 和 Windows SDK。本机脚本会自动使用项目上一级已有的 .rustup-home / .cargo-home 配置。

~~~powershell
powershell -ExecutionPolicy Bypass -File .\tools\build.ps1
powershell -ExecutionPolicy Bypass -File .\tools\build.ps1 -Action test
~~~

发布构建使用 target/verified，避免覆盖仍在运行的旧版 target/release/focus-island.exe，最终复制到 dist/FocusIsland.exe。运行中的发布 exe 必须退出后才能覆盖。

## 平台打包

Windows x64 便携包由 `tools/package-windows.ps1` 生成，输出 `dist/FocusIsland-1.0.0-windows-x64.zip`，包含程序、中文使用说明和校验文件。解压后运行 `FocusIsland.exe`；电脑需要 Microsoft Edge WebView2 Runtime。打包使用独立暂存目录，不覆盖正在运行的 `dist/FocusIsland.exe`。

~~~powershell
powershell -ExecutionPolicy Bypass -File .\tools\package-windows.ps1
# 复用已经验证的 target/verified/release 构建
powershell -ExecutionPolicy Bypass -File .\tools\package-windows.ps1 -SkipBuild
~~~

macOS 的窗口、菜单、通知、数据目录和命令类型已按平台适配。`.github/workflows/package.yml` 分别使用 Apple Silicon 和 Intel macOS runner 构建 ZIP/DMG，构建失败或 GUI 自检失败不会输出 Mac 包。此前提交 `a4c5885` 的两个 Mac 构建及 GUI 自检已通过；最新本地改动的云端验证待运行。Mac 包默认采用 ad-hoc 签名，未公证。完整上传、打包及平台差异说明见 [PACKAGING.txt](PACKAGING.txt)。

工程包由 `tools/package-source.ps1` 生成，只包含源码、锁定依赖清单、测试/构建脚本和说明，不包含编译缓存、测试数据、用户配置或登录凭据。Actions 新增 `FocusIsland-source` 产物，内含工程 ZIP 和 SHA256 校验文件；平台产物名称保持 `FocusIsland-windows-x64`、`FocusIsland-macos-arm64`、`FocusIsland-macos-x86_64`。

在“通用设置 → 岛的位置”中调整“距顶部”，支持 0–1000 px，默认 20 px。点击“应用”或按 Enter 后立即移动，重启保留；超出屏幕可用区域时自动限制位置，展开、收起与计时状态不受影响。Windows 按所在显示器顶部计距，并按工作区上下边界限制位置，为展开圆盘保留空间；Mac 按菜单栏下方的可用区域顶部计距。保存的是用户设定值，屏幕边界只约束实际位置。

## 自检与回归

~~~powershell
Start-Process .\dist\FocusIsland.exe -ArgumentList '--selftest','--log-file',"$PWD\tools\verify\selftest.log" -Wait
Get-Content .\tools\verify\selftest.log
~~~

--selftest 使用独立临时数据目录，页面就绪后执行 SetShape → TogglePanel → 3 秒计时 → TimerDone → AnimationDone，校验三针基座到圆心距离为 0。成功自动退出（退出码 0），错误或 25 秒超时退出码为 1，不修改日常任务配置。

其他诊断参数：

~~~powershell
.\dist\FocusIsland.exe --verbose
.\dist\FocusIsland.exe --data-dir .\tools\verify\manual-profile --log-file .\tools\verify\manual.log
~~~

普通运行的诊断日志位于 %APPDATA%\FocusIsland\diagnostic.log。WebView2 用户数据也写入应用数据目录，exe 所在目录无需写入权限。

浏览器和真实 Windows 集成回归脚本：

~~~powershell
node .\tools\verify-frontend.cjs
node .\tools\verify-panel-navigation.cjs
node .\tools\verify-webhook-ui.cjs
node .\tools\verify-webhook-native.cjs
node .\tools\verify-relay-ui.cjs
node .\tools\verify-relay-native.cjs
node --test .\deploy\relay\server.test.cjs
node .\tools\verify-native.cjs
node .\tools\verify-top-offset.cjs
node .\tools\verify-flicker.cjs after .\dist\FocusIsland.exe
node .\tools\verify-completion-actions.cjs
node .\tools\verify-completion-actions.cjs --native .\dist\FocusIsland.exe
node .\tools\verify-idle-eyes.cjs
node .\tools\verify-idle-eyes.cjs --native .\dist\FocusIsland.exe
~~~

这些脚本需要 Playwright；本机默认复用上一级 verify-tools/node_modules/playwright，也可通过 PLAYWRIGHT_MODULE 指向已安装模块。前端测试可用 BROWSER_EXE 指定 Chromium/Edge。原生测试在独立 profile 中启动发布版，通过 --debug-port 9457 临时启用本地 CDP（普通运行不开放端口），检查窗口居中、真实鼠标穿透、双窗口控制、秒级计时、归零动效、任务清空和重启恢复；测试结束退出测试实例并恢复鼠标位置。

## 实现说明

| 文件 | 职责 |
|---|---|
| src/main.rs | IPC 路由、双窗口生命周期、托盘菜单、自检、统一诊断日志 |
| src/window.rs | 多显示器原点与 DPI、可配置顶部距离与水平居中、设置面板工作区限制、原生点击区域、提示音与通知 |
| src/state.rs | 状态验证、兼容旧偏好字段、唯一任务 ID、动作配置与原子保存 |
| src/relay.rs | HTTPS 服务器连接、后台轮询、重试、投递回执与凭据隔离 |
| src/webhook.rs | 本机/局域网 HTTP 接收、专属 URL 与 Bearer 鉴权、消息校验、限流与监听生命周期 |
| src/actions.rs | 每轮动作快照、延迟取消、一次执行校验与后台命令执行 |
| ui/app.js | 统一功能路由与子页导航、唯一计时器、真实时钟、待机与鼠标注视、设置交互、裂开特效 |
| ui/styles.css | 深色玻璃、金色强调、电子窗与动画 |
| tools/verify-*.cjs | 前端与实际 WebView2 的回归检查 |

功能面板默认 560×660，按工作区自动限制尺寸；宽度不足 460 px 时菜单转为紧凑横排，内容独立滚动。`ui/app.js` 的 `panelRoutes` 集中声明根功能与子页归属；新增功能时添加页面、菜单项和路由定义，复用页面切换、焦点恢复、滚动记忆和键盘导航，不把业务设置堆回倒计时页。

前端桥接使用 window.ipc.postMessage。设置面板把操作交给主岛，通过 timerState 同步显示；不会另起计时器。原生窗口与 WebView 始终保留 580×580 透明画布，药丸、圆盘和特效共用固定屏幕原点，避免缩放时旧合成帧错位。原生窗口区域随形态限定可见和点击范围；裂开时放开完整画布，避免裁掉碎片与冲击波；原始盘面在碎片之后衔接回归，期间没有空白帧。减弱动态效果（含系统偏好）直接显示完成态。

### Webhook 与自动服务器连接（2026-11-13）

独立 Webhook 菜单接入本机/LAN HTTP 服务与自有服务器 HTTPS 中继；公网日常连接在程序内配置，不需要本机 SSH。专属 URL 支持飞书文本结构；消息更新、撤回、通知队列、计时和待机共用现有行为。更换服务器需重新填写连接密钥，外部投递令牌变化会自动刷新面板地址。

本轮 Rust 125 项、前端通用 11 组、中继服务器 18 项通过；中继 HTTPS 网关与真实 Node 收发 9 项通过。原生 HTTPS 客户端在隔离测试中验证受信证书、拒绝未知证书、不跟随重定向、响应大小限制与总请求超时。macOS ARM/Intel 已完成包含测试的编译检查，未运行本轮 Mac GUI。公网服务 https://webhook.tchenmm.online 已完成实际 HTTPS → Windows 桌面通知 → ACK 的端到端验收；同 ID 消息更新、撤回、停用后恢复接收及应用重启后的待收消息续收均已验证。本轮未执行新的 macOS 云端构建或 Mac 实机验收，Android 真机蓝牙验收仍待完成。服务器队列仍只存内存，服务端重启会清空待收消息。
